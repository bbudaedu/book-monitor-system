如何取得 LINE Channel Access Token

  1. 前往 LINE Developers 網站
  2. 登入您的 LINE 帳號
  3. 建立新的 Provider 或選擇現有的 Provider
  4. 建立新的 Messaging API Channel
  5. 在 Channel 設定中找到 "Channel access token"
  6. 點擊 "Issue" 按鈕產生 Token
  7. 複製 Token 並貼到上方的輸入框中

注意：請妥善保管您的 Access Token，不要分享給他人。
